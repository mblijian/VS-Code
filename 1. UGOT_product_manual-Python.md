# UGOT PRODUCT MANUAL

## Contents

### Introduction

Users can perform more complex secondary development and learning using the UGOT SDK in thirdparty programming tools with a Python environment.

### Python Environment Requirements

Ensure that your computer has Python version 3.7 or above.

If not, you can find the installation package for your operating system on the official Python website.

Python website[:](https://www.python.org/downloads/) [https://www.python.org/downloads/](https://www.python.org/downloads/)

### Installing the SDK

In the command line (cmd), simply enter the following to install the UGOT Python SDK: pip install ugot:

```python
pip install ugot
```

### Upgrading the SDK

When you need to upgrade the UGOT SDK, enter the following command in the command line:

```python
pip install --upgrade ugot  Start Programming
```

Once the Python environment and UGOT SDK are installed, you can start programming directly using third-party programming tools.

Connect UGOT and your computer to the same network.

In UGOT's main control settings, go to [Settings] and check the robot's IP under [About].

Open a third-party programming tool and write your code.

Run the program.

Example code:

```python
from ugot import ugot import time got = ugot.UGOT() got.initialize("Main Control IP")
got.show_light_rgb_effect(255,0,0,0)
# SDK Explanation: show_light_rgb_effect
#    red (int) – [0-255] Red value
#  green (int) – [0-255] Green value
#   blue (int) – [0-255] Blue value
# effect (int) – [0-3] Light effect type 0: Steady 1: Off 2: Breathing 3:
Blinking time.sleep(2)
```


### Main Function Explanation:

Represent the three gestures (rock, paper, scissors) using the numbers 1 to 3. When UGOT makes a move, a random number is selected from these three numbers. Based on the chosen number, the transforming car announces the corresponding gesture. When the player and UGOT simultaneously make a move, the transforming car uses the camera for gesture recognition. If one of the three gestures is successfully recognized, the result is set to the corresponding number. By comparing the numerical results, the winner of the round is determined. If the gesture is not recognized, the transforming car announces the appropriate prompt and returns to reexecute the rock-paper-scissors game. The main program evaluates the wins of UGOT and the player, and if one side wins two rounds, the transforming car executes the corresponding action and ends the rock-paper-scissors game.
