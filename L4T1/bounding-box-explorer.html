Bounding box explorer

The UGOT robot tells us where the center of a face is and how big it is. But cv2.rectangle needs two corners. Drag the sliders to see how the program turns one into the other.

The program

The highlighted lines are the ones the explorer above shows.

# step 1: load face recognition model
got.load_models(['face_recognition'])
# step 2: open the ugot camera and take photo
got.open_camera()
picture_raw = got.read_camera_data()
picture_1D = np.frombuffer(picture_raw, np.uint8)
picture_bgr = cv2.imdecode(picture_1D, cv2.IMREAD_COLOR)
# step 3: define the face_info
face_info = got.get_face_recognition_total_info()
# step 4: draw bounding box
if picture_bgr is None:
    print("I can not find the image.")
else:
    name = face_info[0][0]
    face_x = int(face_info[0][1])
    face_y = int(face_info[0][2])
    face_height = int(face_info[0][3])
    face_width = int(face_info[0][4])
    cv2.rectangle(picture_bgr, (face_x - face_width//2, face_y - face_height//2),
                  (face_x + face_width//2, face_y + face_height//2), (0, 255, 0), 3)
    cv2.putText(picture_bgr, name, (face_x - 30, face_y - 80),
                cv2.FONT_HERSHEY_SIMPLEX, 0.6, (0, 0, 255), 2)
    cv2.circle(picture_bgr, (face_x, face_y), 3, (0, 255, 0), 3)
    jpg_ok, jpg = cv2.imencode(".jpg", picture_bgr)
    if jpg_ok:
        display(Image(data=jpg.tobytes()))

Things to notice

  1. The y-axis points down. (0, 0) is the top-left corner of the image, so the top edge of the box is y - h//2.
  2. Center plus half-size gives the corners. Top-left subtracts half the width and height; bottom-right adds them.
  3. Watch the order. face_info[0] is [name, x, y, height, width], so height (index 3) comes before width (index 4).
  4. putText uses the bottom-left corner of the text. Make the face taller than 160 and the name moves inside the box.
  5. OpenCV colors are BGR, not RGB. (0, 255, 0) is green, but (0, 0, 255) is red.
